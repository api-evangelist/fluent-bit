The original draft post about Fluent Bit while back in 2017… Logging is something that we have to deal with everyday, from the different components available in production is not the most fun area, but something that needs to be done right to perform proper analysis of applications behavior. In the Cloud Native era, managing things at scale requires special handling and focus on performance and resources usage; logging is not the exception.
