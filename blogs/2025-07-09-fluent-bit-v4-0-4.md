🔥 Fluent Bit v4.0.4 is here ! TL;DR: Fluent Bit v4.0.4 introduces a powerful OpenTelemetry interface for better encoding and decoding, enhanced Lua scripting with OTLP metadata access, character encoding conversion for non-UTF-8 logs, and AWS IAM support for Kafka/MSK — plus performance boosts, NFS-tail fixes, and dozens of other improvements. New OpenTelemetry Interface Fluent Bit continues to strengthen its position as a modern OpenTelemetry data pipeline.
